## [0.1] — 2026-09-13

Первая рабочая версия TMC StaffWork.

### Добавлено

- Управление персоналом: добавление/удаление сотрудников, назначение внутренних
  рангов, включение/отключение, хранение UUID, последнего ника, даты добавления
  и того, кто добавил сотрудника.
- Учёт рабочего времени: статусы `WORKING`, `AFK`, `OFF_DUTY`, `BREAK`,
  `MEETING`, `TRAINING`; начало/завершение рабочей сессии; история интервалов
  статусов; статистика за сегодня/неделю/месяц/всё время; настраиваемый список
  статусов, засчитываемых как рабочее время.
- Автоматическое управление статусами: статус и старт сессии при входе,
  поведение при выходе, определение AFK по бездействию с автоматическим
  возвратом из AFK.
- Восстановление после аварийной остановки сервера: незавершённые сессии
  корректно закрываются при следующем запуске по последнему известному
  heartbeat, а не по времени перезапуска.
- Хранилища данных: YAML, SQLite (по умолчанию), H2, MySQL/MariaDB — через
  единый интерфейс репозитория с собственной системой версионирования схемы.
- Команды `/staffwork` (алиас `/sw`): `help`, `info`, `list`, `add`, `remove`,
  `rank set`, `status`, `status set`, `start`, `stop`, `stats`, `reload`,
  `version`, `telegram link|unlink` — с tab-completion и проверкой permission
  на каждую подкоманду.
- Права доступа в формате `tmc.staffwork.<категория>...` с родительскими
  группами `user`, `staff`, `moderator`, `admin`, `*`.
- Планировщик для Paper/Spigot/Folia: региональные и asynchronous-задачи через
  Paper API там, где они доступны, безопасный fallback на `BukkitScheduler` на
  обычном Spigot.
- Мягкая интеграция с PlaceholderAPI: `%tmcstaff_staff_status%` и другие
  плейсхолдеры статуса и рабочего времени.
- Отключаемая по умолчанию интеграция с Telegram: привязка аккаунта по
  одноразовому хешированному коду, уведомления о входе/выходе и начале/конце
  смены, long polling без открытия входящего порта.
- Локализация на русском языке (`messages_ru.yml`) с поддержкой MiniMessage и
  упрощённым legacy-фолбэком для серверов без нативного Adventure.
- GitHub Actions: сборка, тесты, Checkstyle, Spotless на каждый push/PR;
  отдельный workflow публикации GitHub Release по тегу с контрольной суммой
  SHA-256.
